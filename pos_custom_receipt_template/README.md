# Custom Receipt Template for Odoo POS

## Overview

This Odoo module enhances the Point of Sale (POS) system by providing customizable receipt templates. It allows users to create and apply custom receipt designs to better match their branding and business needs.

## Features

- **Multiple Receipt Templates**: Choose from pre-designed receipt templates
- **Custom Receipt Layouts**: Personalize receipt appearance and branding
- **Easy Configuration**: Simple setup through POS configuration
- **Seamless Integration**: Works with existing POS workflow

## Installation

1. Download or clone this module into your Odoo addons directory
2. Update the module list in Odoo
3. Install the "Custom Receipt Templates for POS" module
4. Configure receipt templates in POS settings

## Configuration

1. Go to **Point of Sale > Configuration > Point of Sale**
2. Select your POS configuration
3. In the **Receipt** tab, enable "Is Custom Receipt"
4. Choose a receipt template from the dropdown
5. Save the configuration

## Usage

Once configured, the custom receipt template will be automatically applied when printing receipts from the POS interface.

## Requirements

- Odoo 18.0
- Point of Sale module
